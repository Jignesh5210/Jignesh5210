# 💫 About Me:
I’m a passionate MERN Full Stack Developer and Computer Science student focused on building modern, scalable, and real-world web applications. I specialize in JavaScript-based technologies including React.js, Next.js, Node.js, Express.js, and MongoDB. I enjoy creating responsive UI, secure backend systems, and real-time features that improve user experience.<br><br>One of my major projects is SkillSwap — a full-stack web application built with Next.js, MongoDB, JWT Authentication, and Socket.IO. The platform allows users to connect, exchange skills, send real-time messages, manage sessions, and receive live notifications. While building this project, I worked on authentication systems, REST APIs, real-time communication, state management, and production-level backend architecture.<br><br>I’m continuously improving my skills in full-stack development, problem-solving, and modern web technologies with the goal of becoming a professional software developer and building impactful products.
